# UnderRadar acceptance checks

- Default: eight sourced October 2026 records, velocity ordering falls back visibly to activity proxy, no fabricated history.
- Search, scope tabs (all/releases/demos/watchlist), watch toggle and reset.
- Adjacent genre and current-player filters combine; range slider and minimum/maximum inputs.
- Table sort on every metric, including missing values last both directions.
- Game detail opens, shows evidence timestamps and unavailable follower growth, closes via button and Escape.
- Select up to three games, compare metrics side by side, remove and close.
- Refresh attempts server collection, preserves source snapshots on denial, surfaces access error and cooldown.
- CSV exports only filtered records with metric status, timestamps, sources and blank unknowns.
- Methodology shows daily player/follower formulas, sampling window and proxy limitations.
- Source and Steam links open correct app pages.
- Desktop 1440×1000 and mobile 375×812: no outer horizontal overflow; table scrolls horizontally.
- Empty search, invalid min/max and no measured history handled without crashing.
- Network failure retains previously loaded UI; clean console and no fake live labels.
- No unattended scheduler, private user credentials, persistent browser storage or manufactured charts.
